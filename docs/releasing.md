# Releasing

Release notes are generated by OpenCode Go and used to create a draft GitHub release.

## OpenCode Go Authentication

To authenticate CI, create an OpenCode Go API key from the workspace keys page:

1. Open `https://opencode.ai/workspace/<id>/keys` for the workspace that has OpenCode Go enabled.
2. Create or copy an API key.
3. Add it to this repository as the GitHub Actions secret `OPENCODE_API_KEY`.

To validate the key locally, run `opencode`, use `/connect`, select `OpenCode Go`, and paste the key when prompted.

The workflow defaults to `opencode-go/deepseek-v4-flash`, a lower-cost OpenCode Go model suitable for summarizing release notes. You can list available models with `opencode models opencode-go` after connecting OpenCode Go.

## Draft a Release

Invoke the release workflow locally with npm:

```bash
npm run release
```

This dispatches the GitHub Actions workflow with the GitHub CLI. The workflow reads the release version from `package.json`, creates the `v<version>` tag, compares against the latest existing tag, and drafts the release at the checked-out commit.

You can also invoke the workflow directly with `gh`:

```bash
gh workflow run draft-release.yml
```

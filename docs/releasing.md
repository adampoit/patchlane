# Releasing

Release notes are generated by OpenCode Go and used to create a draft GitHub release.

## OpenCode Go Authentication

To authenticate CI, create an OpenCode Go API key from the workspace keys page:

1. Open `https://opencode.ai/workspace/<id>/keys` for the workspace that has OpenCode Go enabled.
2. Create or copy an API key.
3. Add it to this repository as the GitHub Actions secret `OPENCODE_API_KEY`.

To validate the key locally, run `opencode`, use `/connect`, select `OpenCode Go`, and paste the key when prompted.

The workflow defaults to `opencode/deepseek-v4-flash`, a lower-cost OpenCode Go model suitable for summarizing release notes. You can list available models with `opencode models opencode` after connecting OpenCode Go.

## Draft a Release

Invoke the release workflow locally with the GitHub CLI:

```bash
gh workflow run draft-release.yml \
  -f version=0.3.1 \
  -f from=v0.3.0 \
  -f target=main
```

Optional inputs:

- `tag` overrides the default `v<version>` tag.
- `model` overrides the default OpenCode Go summarization model.
- `from` defaults to the latest local tag discovered by the workflow checkout.
- `target` defaults to `main`.
